    Playback event tape

      A scrub captures its latest input, pauses/seeks, and requests resume immediately on pointer release or change; target presentation and later progress are observational gauges, not play gates. Explicit Pause is the only user pause. Approx transferred bytes estimate unique successfully loaded frame IDs (they do not shrink when C evicts a decoded frame); the decoded-frame metric is current bounded cache occupancy. C keeps a bounded decoded neighborhood; late frame loads cannot paint over a newer target. Try quality=hq, forceFail=a, forceFail=b, forceFail=h, forceFail=webgl, or forceFail=a,b to exercise fallback paths. VP9 and packed matte candidates use decoded pixel probes in addition to canPlayType. H requires a same-origin hevcSrc=/path.mov, hevcAssetId=asset-id, and an untrusted manual override such as hevcQualified=asset:asset-id|device:macos-safari; it shows only one static WebP frame while preparing, never uses canvas/WebGL alpha readback, and falls back to C before requesting or exposing an unqualified or timed-out candidate. A checked-in asset URL/hash/device manifest is still required before any production H use.
